# Instagram UI Redesign (Clone)

This is a **UI redesign of Instagram**, created for learning and portfolio purposes. It includes the login, signup, home feed, stories, reels, messages, and profile screens — recreated in a modern and clean layout.


## Features

- Splash screen with Instagram logo
- Login and Signup screens
- Home feed with posts and like/comments
- Stories and Reels view
- Profile screen with grid layout

##  Tech Stack

- UI Tool Used: (Figma )
- Platform: Mobile App (Mock Screens)
